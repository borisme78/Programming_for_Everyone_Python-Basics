# Програмування для всіх: основи Python

Збірка навчальних завдань для практики основ Python. Кожен файл — окрема програма, яку можна запустити в терміналі.

У завданнях розглядаються введення й виведення даних, числові типи, умовні оператори, обробка помилок, функції та цикли.

## Завдання

| Файл | Що робить програма |
| --- | --- |
| [task_2_1.py](task_2_1.py) | Виводить повідомлення `hello world`. |
| [task_3_1.py](task_3_1.py) | Розраховує оплату праці з підвищеною ставкою за понаднормові години; перевіряє перетворення введених даних на числа через `try` / `except`. |
| [task_4_6.py](task_4_6.py) | Розраховує оплату праці за допомогою функції `computepay`. |
| [task_5_2.py](task_5_2.py) | Знаходить найбільше й найменше серед введених цілих чисел; пропускає некоректне введення. |

## Запуск

Потрібен **Python 3**. Усі програми працюють без додаткових бібліотек.

Відкрийте термінал у папці з файлами проєкту та запустіть потрібне завдання:

```sh
python3 task_2_1.py
python3 task_3_1.py
python3 task_4_6.py
python3 task_5_2.py
```

Кожна команда запускає окрему програму. Якщо вона запитує дані, введіть значення та натисніть Enter.

## Приклади роботи

### Розрахунок оплати праці

У завданнях 3.1 та 4.6 перші 40 годин оплачуються за звичайною ставкою, а кожна наступна — за ставкою × 1,5.

Приклад для `task_4_6.py`:

```text
Enter Hours:45
Rate per hour:10
Pay 475.0
```

За тих самих даних `task_3_1.py` виведе `475.0` без префікса `Pay`.

Для дробових чисел використовуйте крапку, наприклад `10.5`. У поточній реалізації `task_3_1.py` години потрібно вводити цілим числом, наприклад `45`: перевірка понаднормових годин використовує `int(hrs)`. У `task_4_6.py` можна вводити дробові години та ставку.

### Найбільше та найменше число

У `task_5_2.py` вводьте цілі числа по одному. Щоб завершити введення й побачити результат, введіть `done` малими літерами.

```text
Enter a number: 7
Enter a number: 2
Enter a number: cat
Invalid input
Enter a number: 10
Enter a number: 4
Enter a number: done
Maximum is 10
Minimum is 2
```

Після некоректного введення програма продовжує роботу. Якщо завершити її без жодного коректного числа, обидва результати матимуть значення `None`.
